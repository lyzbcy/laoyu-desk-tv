# 日志与反馈

现状：0.3.7正式包，预填GitHub反馈与诊断ZIP回归通过；负责人：捞鱼；最后更新：2026-10-13。

提供明显“遇到问题反馈”入口。日志记录时间、软件版本、平台和有限事件/错误码，不记录视频路径、网页内容/网址、Cookie或凭据。用户可导出或复制摘要，是否附日志由用户控制。

用户明确选择预填GitHub。主进程prepare返回实际正文、经过有限事件/字段过滤的日志及默认诊断ZIP元数据；预览令牌绑定窗口、有有效期，编辑撤销旧令牌并清空旧DOM，异步过期回执不能恢复旧预览。用户确认后仅打开预填页，仍由本人提交；默认ZIP保存到下载目录可拖入附件，取消附带诊断则不为该反馈读取日志或生成ZIP，程序的有限技术日志规则保持。超长备注不截断，明确复制粘贴回退。打开失败保留稿件，重试不重复生成附件。

ZIP只含about.json和diagnostics.jsonl，CRC由独立Python zipfile验证；分享前再次过滤旧日志、限制读取量，未知事件、自由文本、路径/网址/凭据字段均不导出。备注是用户自行填写并预览的公开内容，不能对未经检查的全部文字承诺绝对“无敏感信息”。导出ZIP由用户选路径。

评价/Star邀请仅在累计三个不同上海日期后、主动进入设置时显示；关闭持久保存时间戳，完整15×24小时不再提醒，时钟回拨不能绕过。无启动营销弹窗。企业微信密钥不进入公开客户端或仓库；没有发送真实验收消息。
