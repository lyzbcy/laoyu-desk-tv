# Windows安装体验

现状：0.3.3已发行；原始EXE入口和精确标题的原生可见WPF窗口验收通过；负责人：捞鱼；最后更新：2026-10-10。

按美化规范提供独立WPF前端，原创于本项目，不复制私有软件中心源码。无原生白标题栏，主题按钮/复选框，盘符按钮加可直接编辑的路径；首次优先非系统固定磁盘，已有安装保留原路径。桌面快捷方式、完成后打开由用户选择。安装结果核对实际exe版本及系统记录，再显示成功。

electron-builder NSIS仍为真实后端。自定义customInit只在交互首次入口启动现代界面：提取到独立临时目录后退出，释放安装器互斥锁；WPF按钮才执行同一安装器的/S /D，后台更新直接/S而不经过前端。不能让原NSIS通过ExecWait持锁等待再启动相同安装器，否则互相阻塞。

脚本src/helpers/setup.ps1须UTF-8 BOM。脚本Preview只渲染自己界面并自动截图退出，不安装；Acceptance在真实安装/版本/登记通过后输出本地报告。使用说明与MIT许可附在Windows便携根目录，完整依赖一起保留。
