# 无感与隐私自检

现状：0.3.3品牌版验收。
负责人：捞鱼。
最后更新：2026-10-10。

按用户要求学习E:/共享/创业/lyzbcy-noone-knows-main的memory/03_防捕获与无感、app/src/main/stealth/winStealth.ts和selfCheck.ts。复用设计原则：默认防捕获，浮窗不抢焦点，显示/恢复后补设保护，真实原生状态与外部捕获结果分级，不把API成功等同所有会议软件安全。

范围：播放器和所有应用设置窗口默认防捕获；播放器在伪装模式不进任务栏/Alt+Tab、不激活，用户打开网页设置模式时允许输入；设置提供“无感保护”和“自动自检”两项默认开启的独立开关。关闭保护立即撤销，偏好跨重启/升级保存。启动和系统唤醒后的自动检查只核对原生保护、不可激活与快捷键，不弹窗也不显示校准色，避免打断。用户主动点“完整捕获自检”才执行正/负探针，这一小块色标的短暂显示在按钮旁说明。未执行捕获不能记为通过。

Windows使用Electron保护和user32的原生补设/回读；自检以外部GDI探针验证同一窗口保护路径，并检查焦点保持。仅采样自己的探针小区域，返回计数，不保存、上传桌面图像。Mac设置内容保护并隐藏Dock；ScreenCaptureKit可能绕过，显示警告，不能伪报已通过外部捕获。

探针仅证明当前GDI/DWM路径，不代替OBS、截图工具、远程桌面或目标会议软件的对端预览；未执行项显示未验证。开发回归使用隔离userData，不改变用户会议或系统音量。结果按版本/窗口生命周期更新，关闭或重建窗口不能复用已过期成功。

本机Win10/150%DPI：硬件加速真实窗口，独立GDI正基线3180/3180标记可见；保护窗口3348/0泄露，前台保持；关闭/开启原生标志复验通过，见verification/privacy-windows.json。禁止探针调用setIgnoreMouseEvents(true)或使用透明layered窗口：Win10会返回ERROR_NOT_ENOUGH_MEMORY(8)，即使其他窗口保护已成功也不能把该探针记为通过。测试不得禁用硬件加速后将不显示的正基线当作保护通过。辅助进程设线程DPI意识，获取客户区物理坐标，只在内存取小区域颜色计数。
